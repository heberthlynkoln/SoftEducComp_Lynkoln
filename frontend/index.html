Atalho: Ctrl + Enter
O que este analisador aceita?

Comandos de atribuição no formato identificador = expressão, com identificadores, números, textos entre aspas, operadores + - * / e parênteses. Estruturas como if, while, funções, listas e import estão fora do escopo do parser. O analisador léxico já reconhece palavras reservadas do Python, comentários com # e mais operadores; veja docs/ANALISE-LEXICA.md no repositório.
